# 校园 AI 智能自习室预约系统

《软件工程基础》课程设计项目，课题 1。

## 项目目标

实现校园自习室座位预约、时段锁定、预约冲突拦截、签到核销、违规占座预警、空闲座位推荐、后台权限管理和预约数据统计等功能。

## 分支约定

- `main`：可演示、可提交的稳定版本。
- `dev`：日常集成开发分支。
- 功能开发完成并自测后，再合并到 `dev`；验收前从 `dev` 合并到 `main`。

## 提交约定

提交信息使用“模块：动作”的格式，例如：

```text
预约：增加时段冲突校验
文档：补充预约流程图
测试：增加重复签到用例
```
