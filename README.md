# 校园 AI 智能自习室预约系统
《软件工程基础》课程设计项目。
## 项目简介

本系统面向校园自习室场景，实现座位预约、时段锁定、预约冲突拦截、签到核销、违规占座预警、空闲座位推荐、后台权限管理和预约数据统计等功能。
